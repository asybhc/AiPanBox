# AiPanBox 使用说明

作者：一杯好茶　版本：1.0

## 这是什么

AiPanBox 把百度网盘当成本地硬盘用。影片传到网盘时会自动加密，网盘上看到的都是打不开的文件；在这台电脑上播放时自动解密，可以正常拖动进度条，和看本地电影一样。

只有本机的密钥能解开这些文件。软件不装系统服务、不写注册表，所有数据都放在 `%LOCALAPPDATA%\BaiduVault\`。

## 第一次使用

1. 双击 `AiPanBox.exe`。第一次启动会自动安装需要的组件，大约等 1～2 分钟，看到主界面就可以用了。以后再打开是秒开。
2. 程序里自带一个本地演示库，可以直接上传文件、双击播放，先熟悉操作。

不用再单独运行 `setup-local.ps1`，上面的安装过程程序会自己完成。只有想手动部署或排查问题时，才需要在命令行里运行它。

## 接入自己的百度网盘

软件不能替你授权，这一步要自己在浏览器里完成，大约十分钟。

1. 在浏览器打开百度网盘开放平台的「应用列表」页面（pan.baidu.com/union/console/applist），新建一个「软件应用」，回调地址填 `oob`，建好后记下 AppKey 和 SecretKey。
2. 用下面这个地址授权（把 `{AppKey}` 换成自己的）：

```
https://openapi.baidu.com/oauth/2.0/authorize?response_type=code&client_id={AppKey}&redirect_uri=oob&scope=basic,netdisk&display=popup
```

同意后会得到一串授权码，用它换一个 refresh_token。这串 token 只显示一次，务必抄下来。

3. 回到软件，点「库管理」，再点「添加库」，网盘选「百度网盘」，把 AppKey、SecretKey、refresh_token 填进去，根目录填 `/apps/应用名`。点「连接测试」，通过后点「完成」。
4. 把影片放进网盘的「我的应用数据/应用名」文件夹。

如果你习惯命令行，也可以直接带参数运行 `setup-local.ps1`，参数是 `-BaiduClientId`、`-BaiduClientSecret`、`-BaiduRefreshToken`。

## 主界面

顶部按钮：

| 按钮 | 用途 |
| --- | --- |
| 刷新 | 重新读取网盘文件列表 |
| 库管理 | 添加、修改、删除网盘库 |
| 账号管理 | 查看和管理登录过的账号 |
| 上传 | 把本地影片传到网盘 |
| 设置 | 端口、缓存、播放、开机自启等 |
| 使用说明 | 打开本文档 |

中间是文件列表，双击文件开始播放。

## 上传影片

1. 点「上传」，选「选择文件…」或「选择文件夹…」，也可以直接把文件拖进窗口。
2. 选传到哪个库、传到网盘的哪个目录。不确定目录就点「浏览远端目录…」逐级点进去。
3. 点「开始上传」。想停下就点「暂停」，之后点「继续」会自动跳过已经传完的文件。
4. 每个任务都有进度、速度和校验结果，校验通过说明文件完整。

## 播放

在主界面双击文件就能播放。可以拖动进度条、暂停、继续，下次打开同一个文件会从上次停下的地方接着播。

## 账号管理

主界面点「账号管理」，能看到所有登录过的网盘账号，以及备注、类型、状态和是否挂了库。

- 「编辑凭证」：账号过期或者换了密码时用它重新授权，双击一行也可以打开。
- 「移出挂载」：暂时不显示这个库，登录信息和密钥都保留，随时可以恢复。
- 「删除账号」：登录信息和挂载一起去掉。确认框里有「同时删除加密密钥」的选项，不勾选就只删账号，网盘上的文件不受影响。
- 「重启服务」：改完账号或设置后，让播放服务重新加载。

删除账号不会删掉网盘上的任何文件。

## 备份密钥

这一步最重要。每添加一个库，软件都会生成一套独立的加密密钥，密钥丢了，网盘上对应的文件就再也打不开。

在「库管理」或「设置」里点「导出密钥备份包」，设置一个密码，把生成的文件保存到 U 盘或另一台电脑。备份文件和密码建议分开放。

换电脑或重装系统后，用「导入备份包」选这个文件、输入密码、确认覆盖，密钥和配置就恢复了。

## 设置

- 端口：网盘服务和播放服务在本机的端口，改完会自动重启对应服务。
- 缓存上限：播放时暂存占用的磁盘空间上限，默认 10G。
- 退出时清理播放缓存：打开后关闭软件会删掉解密的临时文件，更私密，但下次播放要重新下载。
- 硬件解码、字幕编码、默认播放行为：按自己的情况调整，不确定就保持默认。
- 开机自启：开机后自动打开软件并启动服务。
- 上传并发数：同时上传几个文件，网络不好就调小。

## 常见问题

| 现象 | 怎么处理 |
| --- | --- |
| 主界面一直提示连接失败 | 完全退出软件（托盘也退出）再打开；仍不行就删掉 `%LOCALAPPDATA%\BaiduVault` 后重新打开，让程序自动重装环境 |
| 刚传的文件在列表里看不到 | 点「刷新」，或者等一分钟再看 |
| 账号状态显示凭证过期 | 进「账号管理」，选中账号点「编辑凭证」重新授权 |
| 播放卡顿、打不开 | 在「设置」里关掉硬件解码再试一次 |
| 窗口一片空白 | 在「设置」里打开软件渲染，然后重启软件 |

## 还需要了解

- 服务只在本机运行，别的设备默认访问不到。
- 一个库对应一套独立密钥，可以同时添加多个库，互不影响。
- 网盘上是加密文件，官方客户端的预览、缩略图、分享功能对它们无效。
- 加密后的文件名会变长，百度限制在 119 个字符左右，特别长的中文片名可能传不上去。
- 缓存目录里是解密后的临时文件，属于隐私内容，不要随意复制或分享。
